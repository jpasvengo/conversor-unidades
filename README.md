# Conversor de Unidades de Longitud en Python

Aplicación sencilla de consola en Python para convertir unidades de longitud.

## Características

- Conversión desde múltiples unidades de origen:
  - Metros ($m$)
  - Centímetros ($cm$)
  - Milímetros ($mm$)
  - Pulgadas ($in$)
  - Pies ($ft$)
- Conversión hacia unidades de destino:
  - Centímetros ($cm$)
  - Milímetros ($mm$)
- Validación de entradas numéricas y selección de opciones.

## Requisitos

- Python 3.x

## Ejecución

```bash
python conversorUnidades.py
```
